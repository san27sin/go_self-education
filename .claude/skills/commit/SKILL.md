# Коммит по уроку

Ты делаешь коммит в учебном репозитории Go Tour. Формат строго такой:

```
lesson #<номер>

<что сделали>
#time: <сколько времени потратили>
```

Автор коммита только пользователь (берётся из git config). Не добавляй строку `Co-Authored-By` и никакие другие упоминания Claude в сообщение.

## Шаги

1. Запусти `git status` и `git diff` (и `git diff --staged`), чтобы увидеть, что изменилось.

2. **Определи номер урока.** Смотри на изменённые файлы (`lessons/lesson_83.go` → 83, `RunLesson83` → 83) и на `case` в `main.go`. 
   - Один урок: `lesson 83`.
   - Несколько уроков: перечисли через запятую, `lesson 82, 83`.
   - Если номер определить нельзя, спроси пользователя. Не угадывай.

3. **Составь описание** (без слова `desc:` и без других меток). Одна-две короткие строки по-русски о том, что реально сделано, по диффу. Например: «добавлен запуск урока через флаг -lesson, разобран интерфейс Image». Не выдумывай то, чего нет в диффе.

4. **Узнай время.** Время ты определить не можешь. Возьми его из аргументов (`$ARGUMENTS`), если пользователь указал, например `40m` или `1h 20m`. Если не указано, **спроси** пользователя, сколько времени потрачено, и дождись ответа. Никогда не подставляй время сам.

5. **Покажи итоговое сообщение** пользователю и дождись подтверждения, если он не написал, что можно коммитить сразу.

6. **Добавь в индекс** только релевантные файлы по имени (`git add <файлы>`), не используй `git add -A` и `git add .`. Не добавляй `go.sum`/`go.mod`-изменения молча: если они в диффе, упомяни это.

7. **Сделай коммит** через `git commit -m` (heredoc для многострочного сообщения). Без `Co-Authored-By`, автор только пользователь.

8. Покажи результат `git log -1 --stat`.

## Правила

- Не делай `git push`, это только локальный коммит.
- Не используй `--amend`, `--no-verify` и другие обходы хуков.
- Если рабочее дерево чистое, скажи об этом и ничего не коммить.
- Не меняй код уроков. Ты только коммитишь то, что написал пользователь.
